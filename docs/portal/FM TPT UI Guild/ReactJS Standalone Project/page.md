This page provides a Template for ReactJS Standalone project.

With this template you can utilize any component from **[MFE-Base](https://dev.azure.com/sc-ado/FMQPR/_git/51358-mfe-base)**  without doing "npm install".

We just need to add the required module into the **importmap.json** file.

📎 [simple-app.zip](attachments/simple-app.zip)

```actionscript3
cd simple=app
npm i
npm start
```

The template includes the required configuration for the unit testing with Jest.
