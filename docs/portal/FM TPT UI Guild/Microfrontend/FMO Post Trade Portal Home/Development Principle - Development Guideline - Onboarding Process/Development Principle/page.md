2. System Design. The Micro frontend System will attach the JSON Web Token into **Single-UI-Authorization** request header for every API Call and the **Micro frontend Team** (**MT**) provides/ shares the** Public Key Cert (PEM file)** to all **Micro frontend Application Team** (**MAT**). It can be used to validate the JSON Web Token. 1. ![](https://confluence.global.standardchartered.com/download/attachments/2636221681/MFE%20with%20MS%20Copy2.jpg?version=1&modificationDate=1681702484000&api=v2)
3. Follow this document for the **JSON Web Token** Validation: **[Single UI SDK - Derivative Strategy Projects - Confluence (standardchartered.com)](https://confluence.global.standardchartered.com/display/DSP/Single+UI+SDK)**
4. Every **MAT** may implement their own **Deployment approach**, either using Container Based or Virtual Machine, and **Deployment Pipeline**. The Micro frontend System needs the URL for the static file and the URL for the API to be configure in NGINX MFE Backend.
5. The **MT** responsible to manage the availability of **MFE Backend** (NGINX, MFE Service, and Static file. See the diagram on point #2).
6. Each **MAT** responsible to manage the availability of their **Application Domain Backend** (Static files, Gateway, etc. See the diagram on point #2).
7. Each **MAT **must follow/ clone the **Container Template** provided by **MT** to develop their **Application Container** (See the diagram on point #1), (This is the **Container Template**: [https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-container.git](https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-container.git)) [In future MT needs to provides CLI to create new Container Project]
8. Each **MAT **must follow/ clone the **Tiles Template** provided by **MT **to develop the **Application Tiles**. (See the diagram on point #1), (This is the **Tiles Template**: [https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-tiles.git](https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-tiles.git)) [In future MT needs to provides CLI to create new Application Tile Project]
9. Any developers from **MAT **can have read and write access to the **Feature Branch only** on **Root Config** ([https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-root-config.git](https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-root-config.git), **Base Container** ([https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git](https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git)), **Container Template**, and** Tiles Template** repositories. 1. ![image2023-4-20_16-54-47.png](attachments/image2023-4-20_16-54-47.png)
10. **MT **have access to read, write, review and approve Pull Request on **Root Config**, **Base Container**, **Container Template**, **Tiles Template** repositories.
