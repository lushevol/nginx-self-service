# Overall Introduction

Markets Operation Portal provides a suite of integrated post-trade tools and services to Financial Markets Operations users to manage post trade activity across Affirmation, Confirmation, Settlements, Report generation and more. Currently we have Trade Blotter, Cashflow Blotter, Exception Blotter, Rules Engine, FlowZero for Ratan, Confirmation, Download Report, etc for Tenant team.
