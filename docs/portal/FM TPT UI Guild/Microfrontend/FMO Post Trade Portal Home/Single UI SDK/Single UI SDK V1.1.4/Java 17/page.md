## <u>1. Purpose</u>

This is for any service who wants to integrate with Single UI Auth Check.

By integrating with this SDK, the individual service will be able to do the JWT token (generated by the Single UI Auth Service) validation automatically by injecting a HTTP request filter into the program.

## <u>2. Release Note</u>

In this version,

- if the JWT has entitlements, then it will take it from JWT
- it stores the session id to the session id black list when logout API is invoked
- it checks the session id against the session id black list
- Move the public certificate to application property
- it has **JwtTokenUtil** **getEntitlementsToken **that can be used to extract entitlements from the **Entitlements JWT. **(see the code example below).
- it has **AuthorizationService getEntitlements**** **that can be used to get entitlements from the EMS2 system. (see the code example below).

## <u>3. Prerequire</u>

- Recommended JDK version: 17
- Springboot application version is 3.1.2 or higher

### 4.2 Additional configurations

#### 4.2.1. supported key properties details

| Key | Type | Mandatory | Explanation |
| --- | --- | --- | --- |
| include-urls | List | false | urls which need to be checked by SDK. starter is using spring path matcher logic to match request path when its value is empty or null, means all urls will be checked (except those in exclude urls) **by default all URLs will be intercepted if no include nor exclude configured** |
| exclude-urls | List | false | urls which will be ignored by SDK when its value is empty or null, means no urls are in exclude urls. **by default all URLs will be intercepted if no include nor exclude configured** |
| pub | String | true | JWT Public certificate. |
| ems2Host | String | false | EMS2 domain. **Production and Non-production will have different value.** |
| userRolesEndpoint | String | false | EMS2 endpoint to get the user Entity and Roles. **Default value is /ems2/rest/account/%s** |
| entitlementEndpoint | String | false | EMS2 endpoint to get the user entitlements. **Default value is /ems2/rest/entitlements/entitlementList** |
| entityList | String | false | List of EMS2 entity on your application |

#### 4.2.2. Sample configurations

```yml
fmoportal:
  auth:
    ems2Host: https://uklvauems01a.uk.standardchartered.com:16443
    userRolesEndpoint: /ems2/rest/account/%s
    entitlementEndpoint: /ems2/rest/entitlements/entitlementList
    entityList:
      - SSIPLUS
      - FSS_SERVICES_PEREGRINE
    include-urls:
      - /api/v1/demo/**
    exclude-urls:
      - /api/v1/home/**
    skip-jwt-headers:
      - "X-Token"
    pub: 
```

#### 4.2.3 User information

- When security check pass, user info(entitlements) will be saved in request object, attributes, to retrieve it, following code could be helpful
- userInfo key contains four parts, ***userId ***(will be user bank id), **e*****ntitlements ***(will be user raw entitlement message), **oud **(will be user information from OUD), and **sessionId**.
- sample code on how to get the userInfo from the http request is as of below
- check this <u>**[JWT Entitlement Contract](https://confluence.global.standardchartered.com/display/DSP/JWT+Entitlement+Contract)**</u> page to understand the **e*****ntitlements ***format.

```java
package com.sc.axessacademy.branchlocator.controller;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.sc.axessacademy.branchlocator.entity.RequestInit;
import com.scb.fmoportal.auth.services.AuthorizationService;
import com.scb.fmoportal.auth.util.JwtTokenUtil;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import javax.servlet.http.Cookie;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;
import java.util.HashMap;
import java.util.Map;
import java.util.Objects;

@RestController
@RequestMapping("/api/v1/demo")
public class DemoController {
    @Autowired
    private JwtTokenUtil jwtTokenUtil;
    @Autowired
    private HttpSession httpSession;
    @Autowired
    private AuthorizationService authorizationService;
    @Autowired
    private ObjectMapper objectMapper;
    @PostMapping("/init")
    public Map<String, Object> init(@RequestAttribute("userInfo") String userInfo, @RequestBody RequestInit requestInit)
            throws JsonProcessingException {
        String entitlements = jwtTokenUtil.getEntitlementsToken(requestInit.getEntitlementsToken());
        if (Objects.nonNull(entitlements)) {
            httpSession.setAttribute("entitlements", entitlements);
            System.out.println("entitlements::"+entitlements);
        }
       return objectMapper.readValue(entitlements, HashMap.class);
    }
    @GetMapping("/sample")
    public Map<String, Object> sample(@RequestAttribute("userInfo") String userInfo) throws JsonProcessingException {
        String entitlements = (String) httpSession.getAttribute("entitlements");
        return objectMapper.readValue(entitlements, HashMap.class);
    }
    @GetMapping("/entitlements")
    public Map<String, Object> entitlements(@RequestAttribute("userInfo") String userInfo) throws JsonProcessingException {
        Map<String, String> userPayload = objectMapper.readValue(userInfo, HashMap.class);
        Map<String, Object> entitlements = authorizationService.getEntitlements(userPayload.get("userId"));
        return entitlements;
    }
    @GetMapping("/logout")
    public String logout(@RequestAttribute("userInfo") String userInfo, HttpServletResponse response) {
        System.out.println(userInfo);
        Cookie sessionCookie = new Cookie("JSESSIONID", "");
        sessionCookie.setMaxAge(0);
        sessionCookie.setPath("/api/ssiplus");
        sessionCookie.setHttpOnly(true);
        sessionCookie.setSecure(true);
        response.addCookie(sessionCookie);
        return "logout";
    }
}
```
