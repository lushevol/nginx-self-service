## <u>1. Purpose</u>

This is for any service who wants to integrate with Single UI Auth Check. By integrating with this SDK, the individual service will be able to do the JWT token (generated by the Single UI Auth Service) validation automatically by injecting a HTTP request filter into the program.

## <u>2. Release Note</u>

In this version,

- we have removed **user-login-max-duration**.
- we changed **userEntitlements **to **entitlements**. So, we have consistent key object in everywhere.
- rename **single-ui-sdk** to **fmoportal-auth-sdk**
- rename **com.scb.ratan** to **com.scb.fmoportal**

## <u>3. Prerequire</u>

- recommended JDK version: 1.8
- Springboot application version is 2.6.6 or higher

### 4.2 Additional configurations

#### 4.2.1. supported key properties details

| Key | Type | Mandatory | Explanation |
| --- | --- | --- | --- |
| include-urls | List | false | urls which need to be checked by SDK. starter is using spring path matcher logic to match request path when its value is empty or null, means all urls will be checked (except those in exclude urls) **by default all URLs will be intercepted if no include nor exclude configured** |
| exclude-urls | List | false | urls which will be ignored by SDK when its value is empty or null, means no urls are in exclude urls. **by default all URLs will be intercepted if no include nor exclude configured** |

#### 4.2.2. URL check logic

1. check if request url is in exclude urls, yes => skip check, no => continue
2. check if includeList is empty, **yes => check token**, no => continue
3. check if request url is matched with include urls, **yes => check token**, no => skip

#### 4.2.3 User information

- When security check pass, user info(entitlements) will be saved in request object, attributes, to retrieve it, following code could be helpful
- userInfo key contains two parts, ***userId ***(will be user bank id), **e*****ntitlements ***(will be user raw entitlement message)
- sample code on how to get the userInfo from the http request is as of below
- check this **[JWT Entitlement Contract]** page to understand the **e*****ntitlements ***format.

```java
@Slf4j
@RestController
public class CustomerController {

    @GetMapping("/sample")
    public String sample(@RequestAttribute("userInfo") String userInfo) {

        System.out.println(userInfo);

        return "sample controller";
    }
}
```

#### 4.2.4. Sample configurations

```yml
fmoportal:
  auth:
    include-urls:
      - /v1/a
      - /v1/path1/*
      - /v1/path2/** 
    exclude-urls:
      - /v2/path1
      - /v2/path2/*
      - /actuator/**
    skip-jwt-headers:				// if add this header, SDK will skip jwt check when input header keys are matched following list
      - "X-Token"
```
