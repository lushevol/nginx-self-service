# Content

We have created 9 dashboards to monitor the Base Container FMO Portal usage and get insight from them.

## Authentication Service

This dashboard is displaying the Authentication Service usage including: normal login, SSO login, extend the session, re-login using the refresh token, and logout.

We provide a raw data that can be downloaded by any team for their needs.

From this dashboard, we can see SSO login and re-login adoption after we have released those features.

![image2023-11-14_16-54-0.png](attachments/image2023-11-14_16-54-0.png)

## Authentication Service Error

Similar with Authentication Service dashboard, it is displaying the errors happen in the Authentication Service as a raw data.

It displays the **traceId **that can be used for further root cause analysis.

![image2023-11-14_16-54-53.png](attachments/image2023-11-14_16-54-53.png)
