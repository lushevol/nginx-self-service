Welcome to FM TPT User Interface (UI) Guild for Micro-frontend (MFE) and ReactJS standalone project.

# Vision

**FM TPT UI Guild aims to achieve a consistent UI design language across FM TPT
**

# Mission

1. To create FM TPT Theme configuration for UI components
2. To provide a repository for UI components and utilities that commonly used
3. To support all the application teams on delivering their value instead of creating UI components and utilities that commonly used
4. To supports all individual contributors are working together for innovation through collaboration
5. To build and grow the team where the FM TPT UI components and utilities can be enjoyed by all.

# Micro-frontend

FM TPT UI for MFE is a React Component that implements [Material-UI](https://mui.com/material-ui/getting-started/overview/) library and share/ expose them using [Single-Spa](https://single-spa.js.org/docs/getting-started-overview) framework.
It is developed in [Base Container](https://dev.azure.com/sc-ado/FMQPR/_git/51358-mfe-base).
